\section{实验问题与评价指标}

实验围绕以下问题展开，各配对应的评价指标：

\begin{itemize}
    \item 自进化闭环是否成立：跨步种子生成成功率、超采样量 $S$ 随步收缩曲线。
    \item 数据能否自主产生：系统生成任务占比、生成任务的多样性。
    \item 奖励是否可信：智能体自述与环境差分的一致率、空差分短路比例。
    \item 采样策略是否有效：淘汰前后优势标准差对比、选组前后训练信号质量。
    \item 系统能否稳定运行：训练监控指标随步变化、终止判据触发情况。
    \item 训练是否有效：奖励均值随步变化、策略更新有效性（pg\_loss／ppo\_kl）。
\end{itemize}

\section{自进化闭环验证}
\label{sec:exp_loop}

本节验证自进化闭环是否成立：系统除初始种子外能否持续自主产生训练任务。评价方法为观测每步的跨步种子生成情况与超采样量 $S$ 的收缩过程：$S$ 从第一步的 $2N$ 起，随每步淘汰逐步收缩至存活组数 $R$，若各步跨步种子生成成功且 $S$ 稳定收缩而不塌缩至零，则闭环成立。收缩曲线如图~\ref{fig:s_shrink} 所示。

\section{差分驱动奖励效果}
\label{sec:exp_reward}

本节验证差分驱动奖励的抗作弊效果：对比裁判依据状态差分打分与依据智能体自述打分的差异，统计智能体自述与环境差分不一致（即潜在作弊）的比例，以及空差分短路（无环境效果直接判 0）的比例。

\section{超采样-淘汰-选组效果}
\label{sec:exp_select}

本节验证超采样-淘汰-选组对训练信号质量的提升：对比淘汰前后组的优势标准差分布，验证淘汰是否有效剔除低质组；对比选组前后训练批次的梯度信号强度，验证选梯度最优组是否提升每步训练信号质量。

\section{强化学习训练效果}
\label{sec:exp_train}

本节分析 GRPO 训练效果：奖励均值随训练步的变化趋势，策略更新的有效性（pg\_loss、ppo\_kl 的合理范围），以及训练前后模型在任务上的表现对比。

\section{系统稳定性与效率}
\label{sec:exp_stable}

本节分析系统的稳定性与资源效率：训练监控指标（奖励标准差、优势标准差、策略 KL 散度）随步的变化，终止判据的触发情况，以及推理／训练异步调度下的资源利用率。

\section{消融实验}

为分离各机制的贡献，设计以下消融：

\begin{itemize}
    \item 去掉超采样-淘汰-选组（训练全部 $S \times n$ 轨迹）：验证选组对训练信号质量的贡献。
    \item 去掉差分驱动奖励（裁判仅看自述）：验证差分取证对抗作弊的贡献。
    \item 去掉跨步状态继承（每步全新沙箱）：验证状态继承对自进化的贡献。
\end{itemize}

本节综合各实验结果，讨论自进化闭环的整体可行性、各机制的相对贡献、以及系统的适用范围与限制。
