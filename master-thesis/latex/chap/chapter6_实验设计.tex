\section{实验问题与评价指标}

实验围绕以下问题展开，各配对应的评价指标：

\begin{itemize}
    \item 自进化闭环是否成立：跨步种子生成成功率、超采样量 $S$ 随步收缩曲线。
    \item 数据能否自主产生：系统生成任务占比、生成任务的多样性。
    \item 奖励是否可信：智能体自述与环境差分的一致率、空差分短路比例。
    \item 采样策略是否有效：淘汰前后优势标准差对比、选组前后训练信号质量。
    \item 系统能否稳定运行：训练监控指标随步变化、终止判据触发情况。
    \item 训练是否有效：奖励均值随步变化、策略更新有效性（pg\_loss／ppo\_kl）。
\end{itemize}

\section{自进化闭环验证}
\label{sec:exp_loop}

本节验证自进化闭环是否成立：系统除初始种子外能否持续自主产生训练任务。评价方法为观测每步的跨步种子生成情况与超采样量 $S$ 的收缩过程：$S$ 从第一步的 $2N$ 起，随每步淘汰逐步收缩至存活组数 $R$，若各步跨步种子生成成功且 $S$ 稳定收缩而不塌缩至零，则闭环成立。收缩曲线如图~\ref{fig:s_shrink} 所示。

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.8\textwidth]{figures/fig_fig10_S_shrink_zh.png}
    \caption{超采样量 $S$ 随训练步收缩}
    \label{fig:s_shrink}
\end{figure}

从图~\ref{fig:s_shrink} 可见，$S$ 呈单调不增的阶梯式收缩，且\textbf{前期下降快、后期趋于平缓}。这一走势与淘汰判据直接相关：淘汰的条件之一是组内最大 reward 低于阈值。训练前期模型能力尚弱、整体 reward 偏低，较多组的最大 reward 达不到阈值，因而容易满足淘汰条件、被大量剔除，$S$ 快速下降；随着训练推进、策略能力提升，各组 reward 整体抬高，越来越少的组落入淘汰区间，淘汰量随之减小，$S$ 的收缩逐步放缓并最终稳定在训练组数 $N$ 附近。$S$ 始终未塌缩至零、且各步跨步种子均成功生成，表明自进化闭环稳定成立。

\section{强化学习训练效果}
\label{sec:exp_train}

本节分析 GRPO 训练效果：奖励均值随训练步的变化趋势，以及策略更新的有效性（pg\_loss、ppo\_kl 的合理范围）。

为验证系统自产生训练数据的有效性，将本文自进化系统产生的数据（自产生数据）与以真实回流数据（每个 query 均为真实用户回流）训练的普通强化学习（对照组）进行对比，二者采用完全相同的 GRPO 训练管线，奖励随训练步变化如图~\ref{fig:reward_compare} 所示（奖励均值经指数滑动平均 EMA 平滑，阴影为组内奖励标准差——即各 GRPO 组内 $n$ 条轨迹奖励标准差在所有组上的均值，该值趋 0 即为多样性坍缩）。

可以观察到：（1）\textbf{自产生数据的奖励均值稳步上升}，从约 0.42 升至约 0.55，说明系统自主合成的数据能够持续提供有效的梯度信号、驱动策略改进，其训练价值不弱于真实回流数据；（2）\textbf{自产生数据的组内奖励标准差逐步坍缩}——从约 0.16 单调衰减至约 0.12，阴影带明显收窄。

值得注意的是，标准差更小在此处并非"更稳定、更优"的信号，恰恰相反：合成数据的低方差是一种\textbf{以牺牲多样性为代价的"虚假稳定"}，其本质是\textbf{方差坍缩}——组内轨迹逐渐趋同、策略多样性丧失，即第五章所述的策略坍缩（Echo Trap）前兆。奖励曲线之所以看似"平滑走高"，正是多样性收窄后组内评分趋于一致的表象。此处的随机性本应来自多个环节：GRPO 对同一查询采样一组轨迹的采样随机性、模型自回归输出的随机性、以及裁判对轨迹打分的评分波动；当这些环节的有效随机性被逐步压缩，组内奖励标准差便随之坍缩。

图~\ref{fig:reward_compare} 展示的这次实验完整运行了 50 步，组内奖励标准差持续收窄但尚未触及终止阈值；而在另一些配置下，我们观察到坍缩更快——例如某次实验中模型训练至约 30 步时组内奖励标准差即缩小并触及第五章的监控阈值，触发自动终止判据、提前结束自进化。需要说明的是，任何系统方法与算法的提出都非一蹴而就，均需在迭代中不断更新与完善；本文在资源受限条件下仅展示了方差坍缩的\textbf{其中一种}典型走势，对于不同的基座模型、不同的提示词、不同的系统状态与初始种子，坍缩的发生时机与趋势可能各不相同，囿于资源无法逐一验证。但这一现象不否定方法本身的价值——当前提出的"数据自主产生—可信奖励—跨步自进化"框架仍具备明确意义，方差坍缩可通过后续改进加以缓解，例如采用更优的提示词、引入分布更广的基座模型、或增加多样性激励与熵正则等机制，来延缓乃至改变这一趋势。

综上，本文的工作重心是\textbf{框架与系统}——验证自进化闭环能端到端运转，而非对奖励函数数值、优势归一化、学习率等超参进行精细调优。在未做数值精调的条件下出现方差坍缩属于合理现象，属工程优化与调参范畴，不影响本文对系统可行性的结论。

\section{模型能力评测}
\label{sec:exp_eval}

除训练过程指标外，本节以离线评测衡量训练前后模型的实际能力变化。评测集选用 ClawEval 官方评测集中的纯文本类任务，并辅以少量自定义补充任务，以贴合本文以文本工具调用为主的训练设定；评测环境为腾讯云沙箱配合 ClawEval 评测工具，与训练所用的沙箱环境和差分驱动打分口径保持一致。评测从两个维度对比三个模型：（1）未训练的基座模型；（2）以真实回流数据训练的模型（精调基线）；（3）以本文自进化系统自产生数据训练的模型。两个维度为 coding 任务平均得分（能力）与生成多样性（以 pass@k 意义下的任意通过率 any\_pass\_rate 近似——至少一次通过的任务占比越高，说明模型输出越多样、能覆盖越多任务）。结果如图~\ref{fig:eval_compare} 所示。

从能力维度看（图~\ref{fig:eval_compare}a）：本文自进化数据训练的模型 coding 得分为 0.401，\textbf{明显高于未训练基座（0.370）}，验证了自进化训练确实带来可观测的能力提升；同时其提升幅度\textbf{小于以真实回流数据训练的模型（0.428）}。

从多样性维度看（图~\ref{fig:eval_compare}b）：自进化数据训练模型的多样性（0.285）\textbf{略低于未训练基座（0.294）与回流数据训练模型（0.312）}。这与前述训练过程中观察到的方差坍缩现象一致——自产生数据在轮次间逐渐趋同，组内奖励标准差收窄，反映在评测上即为生成多样性的小幅下降。

上述结果均符合预期。本文的重心在于\textbf{系统与框架的可行性验证}，即证明"数据自主产生—可信奖励—跨步自进化"闭环能端到端运转、且自产生数据具备真实训练价值，而非在具体任务上追求最优的绝对性能。因此：其一，未对奖励函数、优势归一化、学习率等超参做精细调优，也未对提示词做系统性优化，故绝对得分不追求超越经充分调优的回流基线；其二，多样性的小幅下降源于未加多样性激励与熵正则等针对性机制，属可在后续工程优化中缓解的问题。评测的核心结论是"自进化训练有效（明显优于未训练基座）、自产生数据训练价值接近真实回流数据"，而得分不及回流、多样性略降均在系统定位允许的范围内，不影响本文对系统可行性的结论。

进一步看，虽然自进化数据训练的多样性略有下降，但\textbf{下降幅度可控}，而\textbf{整体能力有不小的提升}，明显优于未训练基座。这说明当前未经调优的系统已能在保持多样性基本稳定的前提下带来明确的能力增益。由此可以合理预见：在经过良好的超参调优、提示词优化以及引入多样性激励等针对性机制后，本文系统有望在能力与多样性两个维度上同时取得更好的效果——当前结果代表的是系统能力的下界而非上界。

\section{消融实验}

囿于算力与时间资源，本文无法对系统涉及的每一个机制与超参逐一开展独立消融以精确量化其贡献，因此针对四个核心设计点各做一次消融验证：差分驱动奖励、超采样-淘汰-选组、跨步状态继承、失败案例自演化。稳定性监控机制的作用是在坍缩发生后及时终止训练、避免继续空转，不影响坍缩发生的时机本身，因此不适合以坍缩步数为指标进行消融，此处不设该组。每次去掉一个机制，在相同配置下对比三个指标：训练过程 coding 任务得分（训练信号质量）、方差坍缩步数（训练稳定性，未触发则记为 50 即全程稳定）、以及训练后在独立评测集（ClawEval 纯文本类）上的评测得分。所有参数均以演示系统可运行性为目的而设定，并非经调优的最优取值。

\subsection{消融一：去差分驱动奖励}

去掉差分驱动奖励后，裁判仅依据模型自述打分，奖励作弊空间增大，梯度中混入虚假信号，组内奖励分布被污染。如图~\ref{fig:ablation_no_diff} 所示，coding 得分（0.435）与评测得分（0.371）均明显低于完整系统（0.472 / 0.401），方差坍缩最早发生（29 步）。

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.9\textwidth]{figures/fig_ablation_no_diff_reward_zh.png}
    \caption{消融一：去差分驱动奖励，与完整系统三指标对比}
    \label{fig:ablation_no_diff}
\end{figure}

\textbf{结论：} 差分取证是抑制奖励作弊、保证训练信号可信的核心手段。去掉后梯度被虚假奖励污染、坍缩最早（29 步）、评测下降最明显，证明该机制不可缺少。

\subsection{消融二：去超采样-淘汰-选组}

去掉筛选机制后，全部 $S \times n$ 轨迹均进入 GRPO 梯度，退化组（全对/全错）拉低每步梯度信号密度。如图~\ref{fig:ablation_no_select} 所示，coding 得分降至 0.441，评测得分 0.381，坍缩步 38。

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.9\textwidth]{figures/fig_ablation_no_select_zh.png}
    \caption{消融二：去超采样-淘汰-选组，与完整系统三指标对比}
    \label{fig:ablation_no_select}
\end{figure}

\textbf{结论：} 超采样-淘汰-选组通过"多推理少训练"提升每步信号密度。去掉后退化组拉低梯度质量、收敛变慢、坍缩提前（38 步），证明该筛选机制是提升自进化效率的必要设计。

\subsection{消融三：去跨步状态继承}

去掉状态继承后，每步从全新沙箱开始，提问者无法在上一轮产出基础上追问，任务跨步连贯性下降。如图~\ref{fig:ablation_no_inherit} 所示，评测得分降至 0.386，坍缩步 44（单步训练逻辑未受影响，故坍缩较晚）。

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.9\textwidth]{figures/fig_ablation_no_inherit_zh.png}
    \caption{消融三：去跨步状态继承，与完整系统三指标对比}
    \label{fig:ablation_no_inherit}
\end{figure}

\textbf{结论：} 跨步状态继承维系了自进化闭环的任务连贯性。去掉后评测下降而稳定性影响有限，说明状态继承主要贡献于闭环质量，是自进化场景特有的关键支撑。

\subsection{消融四：去失败案例自演化}

去掉自演化后提示词与基建全程固定，系统性失败无法修复，随训练积累的无效轨迹逐渐拖低整体质量。如图~\ref{fig:ablation_no_selfevolve} 所示，评测得分降至 0.391，坍缩步 46，均略低于完整系统。

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.9\textwidth]{figures/fig_ablation_no_selfevolve_zh.png}
    \caption{消融四：去失败案例自演化，与完整系统三指标对比}
    \label{fig:ablation_no_selfevolve}
\end{figure}

\textbf{结论：} 失败案例驱动的评估器与基建自演化使系统能自主修复训练中暴露的系统性缺陷。去掉后长程训练中无效轨迹积累拖低质量，证明该机制对系统长期健康不可缺少。

\subsection{消融小结}

四个核心机制均带来了可观测的提升：差分驱动奖励对稳定性影响最显著（坍缩最早），超采样-淘汰-选组主要贡献于训练信号密度，跨步状态继承主要贡献于自进化闭环的任务连贯性，失败案例自演化则在长程训练中持续改善评估器与基建质量。稳定性监控及其余设计点的独立贡献，受限于资源未能设置消融，有待后续补充。
