\section{验证方案}

验证分为三个层级：

\textbf{（1）单元级验证。} 采样、观察者取证、奖励聚合、选组逻辑、跨步种子生成、训练监控指标计算等模块均有单元测试覆盖（239 passed），无 GPU 亦可验证逻辑正确性。

\textbf{（2）系统级验证。} 多卡环境上端到端链路验证，覆盖采样→奖励→淘汰→选组→GRPO 更新→训练监控→跨步种子生成的完整闭环。系统已跑通多个训练步并正常退出。

\textbf{（3）沙箱继承验证。} 跨步沙箱状态存/恢复在真实沙箱上验证，确认文件内容逐字一致、含嵌套目录。

\section{预期分析}

正式训练完成后，预期从以下维度分析系统表现：

\begin{itemize}
    \item \textbf{自进化有效性}：系统除初始种子外是否持续自主产生训练任务，超生量是否随淘汰动态收缩（$S$ 从 $2N$ 逐步收缩至 $R$）。
    \item \textbf{抗作弊效果}：差分驱动奖励是否有效抑制奖励作弊，智能体自述与环境差分的一致性。
    \item \textbf{训练信号质量}：超生-淘汰-选组是否提升了每步训练信号质量（优势标准差、组内奖励标准差）。
    \item \textbf{系统稳定性}：训练是否在终止判据触发前稳定运转，有无模式坍缩或崩溃；训练监控指标（奖励标准差、优势标准差、策略 KL 散度）的变化趋势。
\end{itemize}
