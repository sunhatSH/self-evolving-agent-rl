\chapter{绪论}

\section{研究背景}

近年来，随着大规模预训练与后训练技术的持续发展，大语言模型（Large Language Model，LLM）在语言理解、文本生成、复杂推理和代码生成等任务中展现出较强的通用能力。与此同时，大语言模型的应用形态逐渐由面向单轮文本生成的模型向能够进行任务规划、调用外部工具并与环境持续交互的智能体（Agent）演进\upcite{react,toolformer,codeact}。与传统文本生成任务相比，智能体通常需要在动态环境中执行由多个步骤组成的复杂任务，其最终表现不仅取决于单次输出的正确性，还与任务规划、工具调用、环境状态变化以及多轮决策过程密切相关。因此，如何进一步提升大语言模型在复杂环境中的多步决策与任务完成能力，成为智能体研究中的重要问题。

强化学习（Reinforcement Learning，RL）通过智能体与环境之间的持续交互，根据任务执行过程中获得的奖励信号优化模型策略，为提升智能体的决策能力提供了重要技术路径。近年来，强化学习逐渐应用于大语言模型的复杂推理、代码执行和智能体任务训练\upcite{deepseek_r1,search_r1,agentgym_rl}。其中，以群组相对优势为核心的 Group Relative Policy Optimization（GRPO）\upcite{grpo}通过比较同一任务下多个采样结果的相对表现构造策略优化信号，在无需显式价值模型的情况下实现模型策略更新，为大语言模型强化学习提供了有效的训练范式。然而，将强化学习应用于智能体场景后，训练数据和奖励评估面临的问题更加突出：一方面，智能体强化学习通常需要大量具有一定复杂度和多样性的任务，而人工构造和标注此类任务的成本较高；另一方面，智能体任务的完成情况往往难以通过单一标准答案进行判断，需要综合工具调用记录、执行轨迹以及外部环境状态进行评估，仅依赖生成轨迹或智能体自反馈可能导致奖励评估偏差。

随着大语言模型能力和应用场景不断扩展，传统依赖人工构造任务和固定数据集的训练范式面临进一步的扩展瓶颈。一方面，固定训练数据难以持续覆盖不断增长的任务空间；另一方面，智能体强化学习过程中需要持续产生新的交互轨迹和训练经验，使训练数据的获取成为限制训练规模和持续迭代能力的重要因素。在此背景下，大语言模型自进化（Self-Evolution）逐渐受到关注\upcite{self_evolution_survey,self_improve}。自进化的基本思想是使模型在较少人工干预的情况下，通过“生成—执行—评估—反馈—更新”的循环不断产生新的经验并优化自身能力。这一思想在两个层面上展开：在\textbf{模型层面}，表现为模型自行生成数据、自我评分并筛选后微调自身，衍生出自我博弈、自我奖励、RLAIF、拒绝采样、进化搜索等多种范式\upcite{self_play,self_rewarding,rlaif,absolute_zero}；在\textbf{智能体层面}，则表现为智能体在环境中积累经验，持续改进其记忆、技能库、工具使用、提示词与规划策略，乃至更新底层模型参数。其中，自主产生训练数据是实现自进化的重要环节\upcite{self_instruct,absolute_zero,r_zero}：模型可以利用已有任务和交互经验生成后续任务，并结合执行结果筛选具有训练价值的经验用于策略优化，从而降低对固定任务集合和持续人工数据采集的依赖。对于智能体强化学习而言，进一步利用环境状态及其变化，可以使任务生成、执行反馈和策略更新形成更加紧密的闭环，使训练过程由固定数据集驱动逐渐转变为由模型、任务和环境共同驱动的动态训练过程。本文所构建的系统正是同时贯通这两个层面：它既让模型自主生成数据、以环境为准自我评分、筛选后经强化学习更新自身参数，又让智能体在沙箱环境中积累经验、以失败案例驱动评估提示词与工具/基建的持续演化，从而在一个闭环内同时演化任务、策略、评估器与基建。

然而，当任务生成、奖励评估和策略更新均由系统自动完成时，训练闭环同时面临新的风险。如果奖励评估存在偏差，或者生成的数据质量不足，该偏差可能随着后续任务生成和策略更新被进一步放大\upcite{reward_hacking_def,reward_overoptimization}。例如，智能体可能通过生成符合评价器偏好的行为获得较高奖励，但实际环境状态并未达到任务要求；低质量或重复任务也可能在多轮任务生成过程中不断出现，使训练数据逐渐偏离预期目标。因此，自进化强化学习系统不仅需要具备持续产生训练数据的能力，还需要建立与环境执行结果相结合的奖励评估机制，并对候选训练经验进行质量控制，从而提高训练闭环的稳定性和有效性。

基于上述背景，本文围绕面向智能体的大模型自进化强化学习系统展开研究。本文以少量人工提供的初始任务作为种子，使智能体在沙箱环境中执行任务并获得交互轨迹与环境状态变化，在此基础上自主生成后续训练任务；同时，通过环境状态差异辅助奖励评估，并结合候选轨迹的超采样、质量淘汰与训练组选择，对进入策略优化阶段的训练经验进行筛选，最终利用强化学习更新模型策略，并将更新后的模型用于下一轮任务生成与执行。通过上述机制，构建从任务生成、环境交互、状态观测、奖励评估、经验筛选到策略更新的持续迭代闭环，探索减少人工任务构造依赖并利用环境交互信息持续产生训练数据的实现方法。

\section{研究问题}

基于上述研究背景，本文关注的核心问题是：

\begin{quote}
能否构建一种面向智能体的自进化强化学习系统，以少量人工提供的初始任务作为种子，使模型在训练过程中自主产生后续训练任务与交互经验，并利用环境反馈构建奖励信号，通过有效的数据筛选与策略优化形成能够持续运行的自进化训练闭环？
\end{quote}

围绕这一核心问题，本文进一步将研究内容分解为以下四个子问题：

\textbf{子问题一（训练数据自主产生）}：如何降低智能体强化学习对人工构造任务和外部真实数据的依赖，使系统能够利用已有任务与交互经验自主产生具有训练价值的后续任务？

\textbf{子问题二（环境反馈与奖励评估）}：如何利用交互过程中产生的客观环境状态变化辅助奖励评估，降低仅依赖智能体自述所带来的奖励误判，提高训练信号与实际任务完成情况的一致性？

\textbf{子问题三（评估器与基建自进化）}：在任务与策略之外，如何使评估器与执行基建也随训练持续改进——即根据失败案例在模型侧修正评估标准、在 harness 侧补齐缺失的环境能力，从而缓解奖励评估与执行环境的固有缺陷对训练闭环的制约？

\textbf{子问题四（自进化闭环构建）}：如何将任务生成、环境交互、奖励评估、经验筛选和策略更新组织为持续迭代的训练流程，使上一轮产生的经验驱动下一轮任务生成，并支持系统在预设终止条件下自主运行与监控？

\section{研究内容}

针对上述研究问题，本文设计并实现一套面向智能体的大模型自进化强化学习系统，主要研究内容包括：

（1）\textbf{自进化强化学习问题建模。} 将传统“固定任务集—轨迹采样—奖励计算—策略更新”的强化学习训练流程扩展为“任务生成—环境交互—状态观测—奖励评估—经验筛选—策略更新—任务再生成”的闭环过程，并对系统中的任务状态、环境状态和策略状态进行形式化描述，为后续方法设计与系统实现提供统一的问题模型。

（2）\textbf{自进化强化学习方法设计。} 针对训练任务自主产生、交互经验质量控制以及训练反馈可靠性等问题，设计跨步自进化任务生成、多智能体协作机制、超采样—淘汰—选组、差分驱动奖励、失败案例驱动的评估器与基建自演化以及自进化稳定性控制六个机制，使任务生成与模型训练能够在统一闭环中持续迭代。

（3）\textbf{自进化强化学习系统实现。} 面向上述方法设计实现完整训练系统，包括沙箱环境与状态管理、跨步状态继承、采样与训练解耦、差分驱动奖励回路、训练监控与自动终止等工程模块，实现自进化强化学习流程的自动化运行。

（4）\textbf{实验验证与分析。} 构建基础模型、传统强化学习训练流程及本文完整系统等对照实验，并针对任务生成、状态继承、奖励评估、候选数据筛选等关键机制开展消融实验，从任务生成质量、训练过程稳定性和独立测试任务上的模型能力等多个维度分析系统的有效性与适用范围。

\section{主要贡献}

本文围绕面向智能体的大模型自进化强化学习训练过程，主要贡献如下：

\textbf{贡献一：提出跨步自进化任务生成机制。}\label{contrib:cross_step}
在单轮任务生成的基础上，将上一轮智能体执行产生的任务结果、环境状态及相关执行信息用于后续任务生成，使系统能够从少量初始种子出发持续产生后续训练任务，形成跨训练步骤的任务演化过程。

\textbf{贡献二：提出多智能体协作机制。}\label{contrib:multiagent}
针对单个模型无法同时胜任求解、客观取证与模拟用户追问这三种性质迥异角色的问题，按“能力与确定性分离”的原则将其拆分为执行者、观察者与提问者三个协同智能体：执行者负责在沙箱中求解、提问者以人设驱动追加需求、观察者以环境证据客观取证。三者的分工与协作使训练任务、交互轨迹与环境反馈得以自主产生，且取证不受求解者操纵，为可信奖励提供客观基准。

\textbf{贡献三：设计超采样—淘汰—选组的训练数据筛选机制。}\label{contrib:oversample}
针对智能体强化学习中候选交互轨迹数量较多而有效训练样本有限的问题，通过增加候选轨迹数量，并依次进行低质量样本淘汰和训练组选择，在控制实际训练数据规模的同时提高候选训练经验的利用效率，实现仅训练强信号精选数据的数据筛选流程。

\textbf{贡献四：设计差分驱动的奖励评估机制。}\label{contrib:diff_reward}
针对仅依据智能体自述或生成轨迹进行奖励评估可能产生偏差的问题，引入沙箱环境状态差异作为奖励评估的辅助证据，将智能体行为与实际环境变化进行关联，以降低奖励评估对智能体自反馈的依赖，提高奖励信号的环境可验证性。

\textbf{贡献五：提出失败案例驱动的评估器与基建自演化机制。}\label{contrib:badcase}
在任务与策略之外，将评估器与基建也纳入自进化对象：训练过程中周期性收集失败案例，由大模型综合任务意图、执行轨迹与环境证据判断失败根因在模型还是基建，进而分别对评估提示词进行增量修订或将缺失的基建能力总结为可复用的技能予以补齐，使评估与执行环境随训练持续自我完善。

\textbf{贡献六：提出自进化稳定性控制机制。}\label{contrib:stability}
针对任务生成、奖励评估与策略更新均由系统自动完成时训练闭环可能出现的偏差累积与状态漂移问题，围绕候选数据规模控制、奖励信号约束以及训练状态监控与自动终止等方面设计稳定性控制策略，抑制低质量任务和奖励偏差在多轮迭代中的放大，保障自进化训练过程在预设条件下的持续稳定运行。

\section{论文组织结构}

根据本文的研究内容和研究思路，全文共七章，各章节主要内容如下：

\begin{itemize}
\item 第一章为绪论，介绍本文的研究背景、研究问题、研究内容、主要贡献以及论文整体组织结构。
\item 第二章为相关理论与研究现状，介绍大语言模型智能体、智能体评测环境、智能体强化学习与 GRPO、自进化学习、奖励建模与奖励作弊以及相关训练框架，并对现有研究进行分析。
\item 第三章建立面向智能体的大模型自进化强化学习问题模型，对智能体与环境的交互过程、自进化过程中的系统状态、训练数据与奖励信号进行形式化描述，并明确本文研究的问题边界。
\item 第四章为自进化强化学习的机制设计与实现，将六个核心机制——跨步自进化任务生成、多智能体协作机制、超采样—淘汰—选组、差分驱动奖励、失败案例驱动的评估器与基建自演化以及自进化稳定性控制——的设计原理与工程实现一体化阐述，并给出系统总体架构与整体运行流程。
\item 第五章为实验与结果分析，通过基础模型与强化学习基线实验、关键机制消融实验以及完整系统实验，分析本文方法在任务自主生成、奖励评估、训练数据筛选、训练稳定性和模型能力提升等方面的表现。
\item 第六章为总结与展望，总结本文的主要研究工作和实验结论，分析当前工作的局限性，并对未来可能的研究方向进行展望。
\end{itemize}
