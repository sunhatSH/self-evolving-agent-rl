\chapter{绪论}

\section{研究背景}

大语言模型驱动的智能体已从单轮问答走向多步工具调用与环境交互，在代码沙箱、终端、文件系统等真实环境中通过“思考—调用工具—观察结果”的循环完成任务。要让这类交互式智能体持续变强，强化学习已成为主流手段——直接用交互轨迹上的奖励信号优化策略。

然而，把强化学习用于交互式智能体面临一个根本性瓶颈：训练数据与可信奖励均难以靠人工规模化获得。真实用户回流数据积累慢、覆盖窄，无法及时支撑强化学习所需的轨迹量；而奖励若仅依赖智能体自述，模型会迅速学会谎报完成这一奖励作弊行为。这一“数据与奖励的供给瓶颈”是当前智能体强化学习走向实用化的核心障碍。

\section{研究问题}

本文围绕上述瓶颈，聚焦一个核心研究问题：

\begin{quote}
能否构建一套系统，让智能体在无人工标注条件下自主产生训练数据、自主获得可信奖励，并基于自身经验持续自我进化？
\end{quote}

这一核心问题可分解为三个子问题：

\textbf{子问题一（数据自主产生）}：如何让训练数据的产生不依赖真实用户回流或人工采集，而由系统自主合成？

\textbf{子问题二（奖励可信）}：如何让奖励锚定在环境真实状态而非智能体自述，从机制上抑制奖励作弊？

\textbf{子问题三（自进化闭环）}：如何让系统基于上一轮经验自主生成下一轮训练任务，形成持续自主运转、无需人工干预的自进化闭环？

\section{研究内容}

针对上述问题，本文设计并实现一套面向智能体的自进化强化学习系统，主要研究内容如下：

（1）建立自进化强化学习的问题模型，将传统“固定任务集—采样—奖励—更新”的训练范式扩展为“任务生成—环境交互—状态观测—奖励评估—策略更新—任务再生成”的闭环过程。

（2）设计自进化强化学习方法，包括跨步自进化任务生成、多智能体协作数据生成、超生-淘汰-选组、差分驱动奖励、自进化稳定性控制五个机制。

（3）实现自进化强化学习系统，包括沙箱环境、跨步状态继承、推理与训练异步调度、采样与训练解耦、训练监控与自动终止等工程模块。

（4）通过实验验证各机制的有效性与整个自进化闭环的可行性。

\section{主要贡献}

本文的主要贡献可归纳为四点：

\textbf{贡献一：跨步自进化机制。} 系统在每个训练步完成后，基于上一轮最优轨迹的执行概括与沙箱状态继承，自主生成下一轮训练任务。除初始种子外，后续所有训练查询由系统产生，形成不依赖外部数据的自进化闭环。

\textbf{贡献二：多智能体自主数据产生。} 执行者、观察者、提问者三个协同智能体使训练数据的产生、取证、追问全部自主化，无需人工标注。

\textbf{贡献三：超生-淘汰-选组机制。} 推理超生、淘汰低质组、选梯度最优组训练，以“多推理少训练”提升每步训练信号质量，同时通过淘汰动态收缩超生量。

\textbf{贡献四：差分驱动的抗作弊奖励。} 奖励锚定在沙箱真实状态差分而非智能体自述，从取证机制上抑制奖励作弊。

\section{论文组织结构}

本文共七章，组织如下：

\begin{itemize}
    \item 第一章为绪论，介绍研究背景、研究问题、研究内容、主要贡献与论文组织结构。
    \item 第二章为相关理论与研究现状，综述大语言模型智能体、智能体强化学习、GRPO、自进化强化学习、奖励建模与奖励作弊、强化学习系统等方向，并分析现有研究不足。
    \item 第三章建立面向智能体的自进化强化学习问题模型，给出自进化过程的形式化描述、系统状态与数据流、核心问题与系统边界。
    \item 第四章为自进化强化学习方法设计，阐述跨步自进化、多智能体数据生成、超生-淘汰-选组、差分驱动奖励、稳定性控制五个机制。
    \item 第五章为系统设计与实现，描述系统总体架构、沙箱环境、跨步状态继承、异步调度、训练监控与系统运行流程。
    \item 第六章为实验与结果分析，按“问题—方法—实验”对应关系验证各机制与整个闭环。
    \item 第七章为总结与展望，总结全文工作、主要贡献、局限性并展望未来方向。
\end{itemize}
