\chapter{相关理论与研究现状}

本章综述与本文直接相关的理论基础与研究现状：大语言模型智能体及其评测环境（2.1--2.2）、智能体强化学习与 GRPO（2.3--2.4）、自进化学习（2.5）、失败归因与评估器/基建自演化（2.6）、奖励建模与奖励作弊（2.7）、智能体强化学习系统与训练框架（2.8），并在此基础上分析现有研究的不足，明确本文的定位。

\section{大语言模型智能体}

大语言模型智能体在代码沙箱、终端、文件系统等真实环境中，通过“思考—调用工具—观察结果”的循环完成多步任务。ReAct\upcite{react} 首先将推理与行动统一在语言模型的生成过程中，使模型能够以交错的思维链与工具调用求解多步问题，成为当前交互式智能体的基础范式。Toolformer\upcite{toolformer} 证明语言模型可以通过自监督方式学习何时、如何调用外部工具，将 API 调用内化为模型能力。在交互经验的组织层面，Reflexion\upcite{reflexion} 让智能体以语言化的自我反思积累经验并在后续尝试中改进；Voyager\upcite{voyager} 在开放游戏环境中以自动课程驱动技能库的持续扩张，是“经验自主积累”的早期代表。CodeAct\upcite{codeact} 进一步表明，以可执行代码作为统一动作空间比离散工具调用更精确、更可组合，本文的执行者即采用代码沙箱内的 ReAct 循环。多智能体协作方面，CAMEL\upcite{camel} 通过角色扮演的双智能体会话规模化地生成指令数据，验证了“以智能体对话产生训练数据”的可行性，这一思路与本文的提问者—执行者协作直接相通。

这类交互式智能体的能力提升，既依赖模型本身的推理能力，也依赖在真实环境中的大量交互经验。如何低成本地获得这些交互经验，是智能体训练的关键问题。

\section{智能体评测环境}

智能体研究的发展伴随着评测环境的成熟。WebShop\upcite{webshop} 构建了首个大规模真实网页购物环境，支持以自然语言指令驱动的多步网页交互；WebArena\upcite{webarena} 将其扩展为可自托管的现实网站集合，成为网页智能体训练与评测的标准环境。在软件工程方向，SWE-bench\upcite{swebench} 从真实 GitHub issue 构建任务，要求模型在真实仓库中定位并修复缺陷；SWE-agent\upcite{sweagent} 设计了智能体—计算机接口（ACI），显著提升了智能体在该类环境中的表现。通用评测方面，AgentBench\upcite{agentbench} 汇聚八个环境，系统评测大模型作为智能体的多步决策能力；AgentBoard\upcite{agentboard} 提供多轮智能体的细粒度分析框架。操作系统层面，OSWorld\upcite{osworld} 提供真实计算机环境中的开放任务基准；TheAgentCompany\upcite{theagentcompany} 则模拟真实公司组织中的长程任务。这些环境覆盖了网页、代码、终端、桌面等多种交互场景，但它们主要作为\textbf{静态评测基准}存在：任务集合固定、人工构建，训练阶段难以直接从中持续获得与策略能力匹配的新任务——这正是本文自进化任务生成所要弥补的缺口。

\section{智能体强化学习与 GRPO}

强化学习通过交互轨迹上的奖励信号直接优化策略，是提升交互式智能体能力的主流手段。策略优化层面，PPO\upcite{ppo} 以裁剪目标函数实现稳定的策略梯度更新，是 RLHF 时代的默认算法；DPO\upcite{dpo} 则绕过显式奖励模型直接从偏好数据优化策略，但难以处理带环境反馈的序列决策。GRPO（Group Relative Policy Optimization）\upcite{grpo} 对同一查询的一组 rollout 做组内奖励归一化来估计优势，省去了价值网络，成为当前智能体强化学习的主力算法。围绕 GRPO 的分析持续深入：Dr.GRPO\upcite{dr_grpo} 指出其长度归一化引入的长度偏置；DAPO\upcite{dapo} 通过解耦裁剪与动态采样在大规模训练中提升稳定性；理论工作\upcite{grpo_dpo} 进一步揭示 GRPO 的方差缩减主要由每步 rollout 总数（查询数 $\times$ 组大小）驱动，为通过扩大采样规模提升训练信号质量提供了理论依据——本文的超采样-淘汰-选组机制正是对这一结论的系统性利用。在多轮智能体训练中，ArCHer\upcite{archer} 提出分层 actor-critic 分离轮级与 token 级信用分配；GiGPO\upcite{gigpo} 以组内分组结构降低多轮优势估计的方差；RAGEN\upcite{echo_trap} 则系统研究了多轮训练中的策略多样性坍缩（Echo Trap）现象：策略在训练中逐渐丧失多样性、所有轨迹趋于一致，导致梯度信号消失、训练停滞。这一发现直接支撑了本文将稳定性监控作为自进化系统的核心组件。

在真实环境中的智能体强化学习已有一批标志性实践：UI-TARS\upcite{uitars} 在 GUI 环境中以大规模合成轨迹与在线 RL 训练端到端 GUI 智能体；GLM-4.5\upcite{glm45} 将智能体能力作为核心训练目标；Kimi k1.5\upcite{kimi_k15} 与 DeepSeek-R1\upcite{deepseek_r1} 证明了大规模强化学习能够有效激发推理能力；Kimi K2\upcite{kimi_k2} 与通义 DeepResearch\upcite{tongyi_dr} 将 agentic 强化学习推进到工具调用与深度研究场景；Search-R1\upcite{search_r1} 训练模型在推理中主动调用搜索引擎；SWE-RL\upcite{swerl} 在软件演化数据上进行基于规则奖励的强化学习；SWEET-RL\upcite{sweet_rl} 研究多轮协作任务的信用分配；AgentGym-RL\upcite{agentgym_rl} 在多环境中进行多轮强化学习以训练长程决策。这些工作验证了智能体强化学习的有效性，但它们的任务供给依赖固定数据集或人工构建的环境内置信号，奖励依赖可验证规则或环境回报，尚未解决开放交互场景下数据与奖励的自主供给问题。

\section{自进化强化学习}

自进化的核心思想是让模型通过自身产生的经验持续优化，而非依赖固定的外部数据集。在文本推理层面，这一方向已有系统性积累：Self-Improve\upcite{self_improve} 以自一致性筛选自生成答案实现自我提升；Self-Instruct\upcite{self_instruct} 与 Evol-Instruct\upcite{evol_instruct} 以自生成与演化指令扩充训练数据；ReST\upcite{rest} 迭代式地在自采样数据上训练；SPIN\upcite{self_play} 将自我提升形式化为自我博弈。更进一步，Self-Rewarding\upcite{self_rewarding} 让模型自评偏好充当奖励信号；SEAL\upcite{seal} 让模型自行生成自我改写以更新自身；Absolute Zero\upcite{absolute_zero} 以“提案—求解”双角色自我博弈，在零外部数据下训练推理器；R-Zero\upcite{r_zero} 用导师—求解者—验证者三角色从零数据自进化出推理模型，其多角色分工与本文的三智能体协作在结构上相近。RFT 的持续微调研究\upcite{rft_forgetting} 还表明，强化学习式微调比监督微调更不易遗忘，为以强化学习驱动持续进化提供了动机。

在交互式智能体层面，自进化也开始被探索：AgentGym\upcite{agentgym} 让智能体在多环境中以指令进化持续提升能力；WebRL\upcite{webrl} 为网页智能体构建自进化在线课程——从失败任务合成新指令并动态调整难度，是“任务自主生成驱动智能体训练”的代表性工作。自进化方向的综述\upcite{self_evolution_survey} 将这类系统归纳为“经验积累—自我反思—能力更新”的循环。总体而言，现有自进化工作在核心思想上与本文一致——基于历史经验自主产生新训练信号，但它们主要停留在\textbf{文本层面}：任务由语言模板演化生成，环境反馈以文本匹配或规则判分给出，未涉及交互式智能体的\textbf{环境状态}在训练轮次间的传递与继承。而后者恰是真实沙箱环境中自进化的关键——智能体在上轮产出的文件与配置上继续工作，任务与状态才能形成有意义的演化链。

\section{失败归因与评估器、基建的自演化}

除任务与策略外，评估器（打分与提问的提示词）与工具集/基建也是可被自主演化的对象，这一方向的研究可归纳为三条线索。其一，\textbf{失败归因与自我调试}：Reflexion\upcite{reflexion} 让智能体以语言化反思定位失败原因并在后续尝试中修正；Self-Debug\upcite{self_debug} 教会大模型通过阅读执行结果解释并调试自身生成的代码，说明大模型具备对失败案例做根因分析的能力。其二，\textbf{提示词自动优化}：APE\upcite{ape} 将提示词搜索形式化为大模型驱动的指令生成与筛选，达到人类水平的提示词工程；ProTeGi\upcite{apo_gradient} 以自然语言“梯度”与束搜索迭代改写提示词，验证了提示词可依据失败样本被自动、增量地修订。其三，\textbf{工具与技能的自主创建}：Voyager\upcite{voyager} 在开放环境中将成功经验固化为可复用的技能库并持续扩充；CREATOR\upcite{creator_tool} 让大模型在缺乏现成工具时自行创建工具以解决问题；Toolformer\upcite{toolformer} 则表明工具使用能力可被模型自监督地内化。这些工作分别证明了失败可被大模型归因、提示词可被自动优化、工具/技能可被自主创建。

然而，现有工作大多在\textbf{推理或部署阶段}、针对单个任务孤立地进行反思、调试或工具创建，尚未将“失败归因—提示词/基建演化”整合进\textbf{强化学习训练闭环}，也很少区分失败的根因究竟在\textbf{模型}（策略的规划、工具使用、方案选择失误）还是在\textbf{基建}（沙箱、工具、执行环境的缺陷）——而这一区分恰恰决定了应当修正提示词还是扩展基建。本文正是针对这一空白，在训练过程中周期性收集失败案例，由大模型综合任务意图、轨迹与环境证据做出模型/基建的归因，进而分别演化评估器提示词或将缺失的基建能力总结为可复用的技能（skill）予以补齐，使评估器与基建随训练持续自我完善。

\section{奖励建模与奖励作弊}

奖励的可信性是强化学习的核心问题。RLHF\upcite{instructgpt} 以人工偏好训练奖励模型，但奖励模型本身可能被策略过度优化——Goodhart 效应使得策略学会欺骗代理奖励而非真正完成任务\upcite{concrete_problems,reward_overoptimization}。Skalse 等\upcite{reward_hacking_def} 对奖励作弊（reward hacking）给出了形式化定义与刻画，指出其根源在于代理奖励与真实目标的对齐偏差。可验证方向上，GSM8K 的验证器\upcite{verifier_gsm8k} 与过程奖励模型 PRM\upcite{prm_step_by_step} 以最终答案或逐步判分提供确定性信号，但仅适用于答案可验证的封闭任务。RLAIF\upcite{rlaif} 与 LLM-as-a-judge\upcite{llm_judge} 将裁判推广到开放任务，生成式验证器\upcite{gen_verifier} 进一步将奖励建模统一为下一个 token 预测。然而近期研究警示了奖励信号的脆弱性：Spurious Rewards\upcite{spurious_rewards} 发现在部分基座上随机奖励也能产生与真实奖励相当的提升，说明奖励信号与能力提升之间的因果关系远比预期复杂。对交互式智能体而言，问题更加尖锐：若裁判看到的只是智能体自述的轨迹文本，模型会迅速学会在轨迹中谎报完成，而裁判无从核实。如何让奖励锚定\textbf{环境真实状态}而非智能体叙事，是奖励可信化的核心问题，当前尚未被充分解决——本文以确定性状态差分为取证依据的奖励机制正是针对这一问题。

\section{智能体强化学习系统与训练框架}

大规模强化学习系统为智能体训练提供工程底座。推理侧，vLLM\upcite{vllm} 以 PagedAttention 实现高吞吐内存管理，成为主流推理引擎。训练框架侧，verl（HybridFlow）\upcite{verl} 以混合编程模型统一单控制器的灵活性与工作流的高效性，支持推理与训练的灵活编排，本文即以其官方注入点接入自定义采样与选组层；OpenRLHF\upcite{openrlhf} 提供易用的全栈 RLHF 管线；AReaL\upcite{areal} 以大规模异步架构解耦 rollout 与训练，提升异构任务的吞吐；Agent Lightning\upcite{agent_lightning} 专注任意交互式智能体的 RL 微调，提供无需修改智能体实现的训练接入。这些框架解决了“如何高效训练”的问题，但框架本身不提供数据自主产生、奖励可信取证、跨步状态继承等自进化所需的核心机制，这些机制需在框架之上自行设计与集成。

\section{现有研究分析}

综合上述方向，现有研究呈现如下格局：算法层面（PPO、GRPO 及其变体）已较成熟，大规模智能体强化学习实践已有充分验证；评测环境覆盖网页、代码、终端等场景，但作为静态基准存在；自进化方向已有文本层面的系统探索（Self-Instruct、SPIN、Absolute Zero、R-Zero），并开始进入智能体场景（AgentGym、WebRL）；奖励建模已有 RLHF/RLAIF/裁判方案与作弊理论刻画；工程层面已有成熟的训练框架。然而，将这些要素整合为一套“自主、可信地供给训练数据与奖励，并持续自进化运转”的完整系统，仍存在明显空白：

（1）数据供给仍依赖人工采集或固定数据集，缺乏交互式智能体在真实沙箱环境中的自主数据产生机制；

（2）奖励仍主要基于智能体自述文本或可验证规则，缺乏锚定环境真实状态的取证机制，难以在开放任务上同时兼顾覆盖面与抗作弊性；

（3）自进化仍停留在文本层面，任务由模板演化生成、反馈以规则判分，缺乏交互环境状态在训练轮次间的继承，任务难度与环境实际状态脱节。

（4）失败归因与提示词/工具自演化虽已有研究，但多在部署阶段针对单任务孤立进行，未整合进训练闭环，也很少区分失败根因在模型还是基建，缺乏据此分别演化评估器提示词或补齐基建能力的机制。

本文正是面向这一空白，以多智能体协作合成数据、差分驱动奖励、跨步自进化闭环（含沙箱状态继承与稳定性监控）、以及失败案例驱动的评估器与基建自演化，构建一套自进化强化学习系统。

\section{本章小结}

本章综述了大语言模型智能体与评测环境、智能体强化学习与 GRPO、自进化学习、奖励建模与奖励作弊、训练框架等方向的理论基础与研究现状，并分析指出：现有工作在算法与工程层面已较成熟，但在“如何自主、可信地供给训练数据与奖励，并使系统在真实环境中持续自进化运转”这一系统与数据层面仍有明显空白。本文的工作正是面向这一空白展开。
