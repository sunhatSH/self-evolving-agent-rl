\chapter{相关理论与研究现状}

本章综述与本文直接相关的理论基础与研究现状。其中 2.1--2.2 介绍大语言模型智能体及其评测环境，作为全章的共性背景；自 2.3 起各节大体沿本文方法的脉络组织：智能体强化学习与 GRPO（2.3）、自进化强化学习（2.4）、奖励建模与奖励作弊（2.5）、失败归因与评估器/基建自演化（2.6），最后在此基础上分析现有研究的不足，明确本文的定位。

\section{大语言模型智能体}

大语言模型智能体在代码沙箱、终端、文件系统等真实环境中，通过“思考—调用工具—观察结果”的循环完成多步任务。ReAct\upcite{react} 首先将推理与行动统一在语言模型的生成过程中，使模型能够以交错的思维链与工具调用求解多步问题，成为当前交互式智能体的基础范式。Toolformer\upcite{toolformer} 证明语言模型可以通过自监督方式学习何时、如何调用外部工具，将 API 调用内化为模型能力。在交互经验的组织层面，Reflexion\upcite{reflexion} 让智能体以语言化的自我反思积累经验并在后续尝试中改进；Voyager\upcite{voyager} 在开放游戏环境中以自动课程驱动技能库的持续扩张，是“经验自主积累”的早期代表。CodeAct\upcite{codeact} 进一步表明，以可执行代码作为统一动作空间比离散工具调用更精确、更可组合，本文的执行者即采用代码沙箱内的 ReAct 循环。多智能体协作方面，CAMEL\upcite{camel} 通过角色扮演的双智能体会话规模化地生成指令数据，验证了“以智能体对话产生训练数据”的可行性，这一思路与本文的提问者—执行者协作直接相通。

这类交互式智能体的能力提升，既依赖模型本身的推理能力，也依赖在真实环境中的大量交互经验。如何低成本地获得这些交互经验，是智能体训练的关键问题。

\section{智能体评测环境}

智能体能力的度量依赖标准化的评测环境。本文的模型能力评测选用 ClawEval——一个面向自主智能体的评测集，其任务在真实代码沙箱中执行、以工具调用完成，并配有官方 grader 按多维 rubric 打分。相比以最终答案匹配为主的封闭式基准，ClawEval 的任务贴近本文以文本工具调用为主的训练设定：任务在沙箱内多步求解、评分锚定于真实执行结果，与本文训练所用的沙箱环境和差分驱动打分口径同构，因而可作为衡量训练前后模型能力变化的客观依据。本文取其纯文本类任务，并辅以少量自定义补充任务用于离线评测（详见第~\ref{sec:exp_eval} 节）。

\section{智能体强化学习与 GRPO}

\subsection{PPO 与 GRPO 及其改进}

强化学习通过交互轨迹上的奖励信号直接优化策略，是提升交互式智能体能力的主流手段。PPO\upcite{ppo} 以裁剪目标函数实现稳定的策略梯度更新，是 RLHF 时代的默认算法，也是本文所用 GRPO 的基础。GRPO（Group Relative Policy Optimization）\upcite{grpo} 对同一查询的一组 rollout 做组内奖励归一化来估计优势，省去了价值网络，是本文采用的策略优化算法。围绕 GRPO 的改进中，DAPO\upcite{dapo} 通过解耦裁剪与动态采样在大规模训练中提升稳定性，其“动态采样、过滤无效组”的思路与本文的超采样-淘汰-选组一脉相承；理论工作\upcite{grpo_dpo} 进一步揭示 GRPO 的方差缩减主要由每步有效 rollout 总数驱动，为本文通过扩大采样规模、再精选高信号组提供了直接的理论依据。此外，多轮训练中的策略多样性坍缩（Echo Trap）现象\upcite{echo_trap}——策略逐渐丧失多样性、所有轨迹趋于一致，导致梯度信号消失、训练停滞——直接支撑了本文将稳定性监控作为自进化系统的核心组件。

\subsection{真实环境中的智能体强化学习}

在真实环境中的智能体强化学习已有一批标志性实践\upcite{deepseek_r1,search_r1,agentgym_rl}，验证了强化学习激发智能体推理与工具调用能力的有效性，但它们的任务供给依赖固定数据集或人工构建的环境内置信号，奖励依赖可验证规则或环境回报，尚未解决开放交互场景下数据与奖励的自主供给问题。

\section{自进化强化学习}

\subsection{文本层面的自进化}

自进化的核心思想是让模型通过自身产生的经验持续优化，而非依赖固定的外部数据集。在文本推理层面，这一方向已有系统性积累：Self-Improve\upcite{self_improve} 以自一致性筛选自生成答案实现自我提升；Self-Instruct\upcite{self_instruct} 与 Evol-Instruct\upcite{evol_instruct} 以自生成与演化指令扩充训练数据；ReST\upcite{rest} 迭代式地在自采样数据上训练；SPIN\upcite{self_play} 将自我提升形式化为自我博弈。更进一步，Self-Rewarding\upcite{self_rewarding} 让模型自评偏好充当奖励信号；SEAL\upcite{seal} 让模型自行生成自我改写以更新自身；Absolute Zero\upcite{absolute_zero} 以“提案—求解”双角色自我博弈，在零外部数据下训练推理器；R-Zero\upcite{r_zero} 用导师—求解者—验证者三角色从零数据自进化出推理模型，其多角色分工与本文的三智能体协作在结构上相近。RFT 的持续微调研究\upcite{rft_forgetting} 还表明，强化学习式微调比监督微调更不易遗忘，为以强化学习驱动持续进化提供了动机。

\subsection{交互式智能体层面的自进化}

在交互式智能体层面，自进化也开始被探索：AgentGym\upcite{agentgym} 让智能体在多环境中以指令进化持续提升能力；WebRL\upcite{webrl} 为网页智能体构建自进化在线课程——从失败任务合成新指令并动态调整难度，是“任务自主生成驱动智能体训练”的代表性工作。自进化方向的综述\upcite{self_evolution_survey} 将这类系统归纳为“经验积累—自我反思—能力更新”的循环。总体而言，现有自进化工作在核心思想上与本文一致——基于历史经验自主产生新训练信号，但它们主要停留在\textbf{文本层面}：任务由语言模板演化生成，环境反馈以文本匹配或规则判分给出，未涉及交互式智能体的\textbf{环境状态}在训练轮次间的传递与继承。而后者恰是真实沙箱环境中自进化的关键——智能体在上轮产出的文件与配置上继续工作，任务与状态才能形成有意义的演化链。

本文的部分工作和思路则参考了以上的研究或工作，并在这些研究的基础之上进行改进、整合并加以创新。

\section{奖励建模与奖励作弊}

\subsection{奖励模型与奖励作弊理论}

奖励的可信性是强化学习的核心问题。RLHF\upcite{instructgpt} 以人工偏好训练奖励模型，但奖励模型本身可能被策略过度优化——Goodhart 效应使得策略学会迎合代理奖励而非真正完成任务\upcite{concrete_problems,reward_overoptimization}。Skalse 等\upcite{reward_hacking_def} 对奖励作弊（reward hacking）给出了形式化定义与刻画，指出其根源在于代理奖励与真实目标之间的对齐偏差。在可验证任务上，GSM8K 的验证器\upcite{verifier_gsm8k} 与过程奖励模型 PRM\upcite{prm_step_by_step} 以最终答案或逐步判分提供确定性信号，此类基于规则或程序校验的奖励在数学、代码等\textbf{结果易于验证}的封闭任务上行之有效。面向开放任务，RLAIF\upcite{rlaif} 与 LLM-as-a-judge\upcite{llm_judge} 将裁判推广到无标准答案的场景，生成式验证器\upcite{gen_verifier} 进一步将奖励建模统一为下一个 token 预测；但近期研究亦警示了奖励信号的脆弱性：Spurious Rewards\upcite{spurious_rewards} 发现在部分基座上随机奖励也能产生与真实奖励相当的提升，说明奖励信号与能力提升之间的因果关系远比预期复杂。

\subsection{智能体任务上的奖励可信化}

对智能体强化学习而言，这一问题更为尖锐：其任务复杂、执行结果的正确性难以程序化校验，即便最终产物看似正确，也难以判断其是否出于可靠的求解过程。更关键的是，若裁判仅依据智能体自述的轨迹文本打分，模型会迅速学会在轨迹中谎报完成，而裁判无从核实。因此，如何使奖励锚定于\textbf{环境的真实状态}而非智能体的自我叙述，是开放交互场景下奖励可信化的核心问题，目前尚未被充分解决。本文以确定性状态差分作为取证依据、并在其上进行多维度评分的奖励机制，正是针对这一问题而设计。

\section{失败归因与评估器、基建的自演化}

\subsection{失败归因、提示词优化与工具创建}

除任务与策略外，评估器（打分与提问的提示词）与工具集/基建也是可被自主演化的对象，这一方向的研究可归纳为三条线索。其一，\textbf{失败归因与自我调试}：Reflexion\upcite{reflexion} 让智能体以语言化反思定位失败原因并在后续尝试中修正；Self-Debug\upcite{self_debug} 教会大模型通过阅读执行结果解释并调试自身生成的代码，说明大模型具备对失败案例做根因分析的能力。其二，\textbf{提示词自动优化}：APE\upcite{ape} 将提示词搜索形式化为大模型驱动的指令生成与筛选，达到人类水平的提示词工程；ProTeGi\upcite{apo_gradient} 以自然语言“梯度”与束搜索迭代改写提示词，验证了提示词可依据失败样本被自动、增量地修订。其三，\textbf{工具与技能的自主创建}：Voyager\upcite{voyager} 在开放环境中将成功经验固化为可复用的技能库并持续扩充；CREATOR\upcite{creator_tool} 让大模型在缺乏现成工具时自行创建工具以解决问题；Toolformer\upcite{toolformer} 则表明工具使用能力可被模型自监督地内化。这些工作分别证明了失败可被大模型归因、提示词可被自动优化、工具/技能可被自主创建。

\subsection{现有空白与本文定位}

然而，现有工作大多在\textbf{推理或部署阶段}、针对单个任务孤立地进行反思、调试或工具创建，尚未将“失败归因—提示词/基建演化”整合进\textbf{强化学习训练闭环}，也很少区分失败的根因究竟在\textbf{模型}（模型在任务分解、工具使用或方案选择上的失误）还是在\textbf{基建}（沙箱、工具、执行环境的缺陷）——而这一区分恰恰决定了应当修正提示词还是扩展基建。本文正是针对这一空白，在训练过程中周期性收集失败案例，由大模型综合任务意图、轨迹与环境证据做出模型/基建的归因，进而分别演化评估器提示词或将缺失的基建能力总结为可复用的技能或扩展工具予以补齐，使评估器与基建随训练持续自我完善。

\section{现有研究分析}

综合上述方向，现有研究呈现如下格局：算法层面（PPO、GRPO 及其变体）已较成熟，大规模智能体强化学习实践已有充分验证；已有面向智能体的标准化评测环境（如本文采用的 ClawEval）可作为模型训练的重要验收标准；自进化方向已有文本层面的系统探索（Self-Instruct、SPIN、Absolute Zero、R-Zero），并开始进入智能体场景（AgentGym、WebRL）；奖励建模已有 RLHF/RLAIF/裁判方案与作弊理论刻画；工程层面已有成熟的训练框架。然而，将这些要素整合为一套“自主、可信地供给训练数据与奖励，并持续自进化运转”的完整系统，仍存在巨大的研究潜力：

（1）数据供给仍依赖人工采集或固定数据集，缺乏交互式智能体在真实沙箱环境中的自主数据产生机制；

（2）奖励仍主要基于智能体自述文本或可验证规则，缺乏锚定环境真实状态的取证机制，难以在开放任务上同时兼顾覆盖面与抗作弊性；

（3）现有训练框架（如 verl\upcite{verl}、OpenRLHF\upcite{openrlhf}、AReaL\upcite{areal} 等）解决的是“如何高效训练”，提供的是通用的采样—更新工程底座，并不包含数据自主产生、奖励可信取证、跨步状态继承、失败归因与系统基建的自我完善等自进化所需的机制；换言之，尚缺少一套将上述环节串接为完整闭环、支撑自进化全流程端到端运转的系统。

（4）失败归因与提示词/工具自演化虽已有研究，但多在部署阶段针对单任务孤立进行，未整合进训练闭环，也很少区分失败根因在模型还是基建，缺乏据此分别演化评估器提示词或补齐基建能力的机制。

本文正是面向上述空白，在通用训练框架之上自行设计并集成各自进化机制，将多智能体协作合成数据、差分驱动奖励、跨步自进化闭环（含沙箱状态继承与稳定性监控）、以及失败案例驱动的评估器与基建自演化串接为一套端到端运转的完整自进化强化学习系统。

\section{本章小结}

本章综述了大语言模型智能体与评测环境、智能体强化学习与 GRPO、自进化学习、奖励建模与奖励作弊、失败归因与评估器/基建自演化等方向的理论基础与研究现状，并分析指出：现有工作在算法与工程层面已较成熟，但在“如何自主、可信地供给训练数据与奖励，并使系统在真实环境中持续自进化运转”这一系统与数据层面仍有明显空白。本文的工作正是面向这一空白展开。
