% 中文摘要

\begin{abstractzh}

大语言模型驱动的智能体在代码沙箱、文件系统等真实环境中通过多步工具调用完成任务，强化学习是让其持续变强的主流手段。然而，交互式智能体的强化学习面临一个根本性瓶颈：\textbf{训练数据与可信奖励均难以靠人工规模化获得}。真实用户回流数据积累慢、覆盖窄；而奖励若仅依赖智能体自述，模型会迅速学会谎报完成这一奖励作弊行为。

本文设计并实现一套面向智能体的自进化强化学习系统，其核心是让智能体在无人工标注条件下\textbf{自主产生训练数据、自主获得可信奖励、自主生成下一轮训练任务}。系统以\textbf{自进化}为第一目标：除初始种子外，后续所有训练查询由系统基于上一轮执行经验自主生成——观察者用大模型概括上轮最优轨迹的执行情况，提问者据此生成符合人设的新种子，沙箱文件系统状态跨步继承到新环境，使智能体在上轮产出的基础上继续工作。超采样-淘汰-选组机制进一步保证每步训练只用梯度最优的轨迹子集，提升自进化效率。

在数据自主产生方面，三个协同智能体把一次采样变成一段自主交互经验：执行者在沙箱中以 ReAct 方式求解任务，观察者对沙箱前后状态作差得到确定性状态差分，提问者基于上轮经验生成下一轮种子。在奖励可信方面，外部冻结裁判依据环境真实状态差分而非智能体自述打分，从取证机制上抑制奖励作弊。此外，系统以\textbf{失败案例驱动评估器与基建的自演化}：周期性收集失败案例，由大模型区分其根因在模型还是基建，进而分别修正提示词或将缺失能力补齐为可复用技能，使自进化从任务与策略扩展到评估器与基建。

系统在 Qwen3.5-9B 上端到端验证，完整自进化链路跑通，沙箱状态跨步继承验证通过。结果表明，少量种子查询即可驱动完整强化学习训练，系统除初始种子外不依赖任何外部数据。

\end{abstractzh}
